# Endometrial cancer adjuvant evidence dashboard

Static, single-page dashboard summarising survival, local control and toxicity from landmark adjuvant trials (PORTEC-1, -2, -3, -4a; GOG-99, -249, -258).

- `data.js` – all extracted figures (edit here to add trials)
- `index.html` – the dashboard (no build step)

Personal reference only; not a clinical decision tool. Source papers are not included in this repository.
